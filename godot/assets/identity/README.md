# Blue Horizon identity

`blue-horizon-badge.svg` is original project artwork designed and written by Codex with AI assistance under
the team's direction, on 2026-11-15. The SVG description also records that provenance. It is a geometric
horizon, sun and return-traverse shield, not a NASA identifier or real agency mission patch. No NASA logo
was used as an input or copied. The file is a vector source rendered by Godot; no raster image-generation
service was used. UI text supplies the project name beside the badge. The same asset is used for decorative
rover/ship markings, with no collision geometry or gameplay effect.
